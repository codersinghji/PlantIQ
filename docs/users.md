# User Roles

## 1. Admin

Responsibilities

- Manage users
- Manage plant information
- Add and remove equipment
- View system reports
- Assign engineers

---

## 2. Engineer

Responsibilities

- Monitor equipment health
- View AI predictions
- Create maintenance work orders
- Analyze sensor data

---

## 3. Technician

Responsibilities

- View assigned work orders
- Update maintenance status
- Record repair details
- Close completed jobs
